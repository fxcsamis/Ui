# ARKITAK Lite — ছোট ভয়েস অ্যাসিস্ট্যান্ট (Kotlin)

কালো ফুল-স্ক্রিনে শুধু অর্ব। কথা বলুন, অর্ব শোনে (listening) → ভাবে (thinking) → বলে (speaking)।

## কীভাবে কাজ করে
- **প্রথমবার খুললে** Gemini API key চায় (aistudio.google.com/apikey থেকে ফ্রি)। কী শুধু এই ফোনে থাকে।
- **মাইক অটো অন/অফ (Google Assistant-এর মতো)**: অ্যাপ খুললে বা অর্বে ট্যাপ করলে শোনে, উত্তরের পর আরেকবার শোনে, চুপ থাকলে নিজে বন্ধ হয়। মেনু থেকে "Mic: always on" করলে কখনো বন্ধ হয় না।
- **অর্বে ট্যাপ** = বলার বা ভাবার সময় থামিয়ে আবার শোনা; শোনার সময় ট্যাপ = মাইক বন্ধ; বন্ধ থাকলে ট্যাপ = শোনা শুরু।
- **দুই আঙুলে চিমটি** = অর্ব ছোট বা বড় করা। ছেড়ে দিলে বাউন্স করে আগের সাইজে ফিরে আসে।
- **অর্বে লং-প্রেস** = সেটিংস (API key, মডেল, ভয়েস ভাষা, ফ্লোটিং অ্যাভাটার)।
- **"floating avatar on করো"** বললে প্রথমবার "অন্য অ্যাপের উপরে দেখানো" পারমিশন চায়। দেওয়ার পর ছোট অর্ব সবসময় স্ক্রিনে থাকে।
  - ছোট অর্বে ট্যাপ = কথা, টেনে সরানো যায়, লং-প্রেস = অ্যাপ খোলা।
  - **"floating avatar off করো"** বললে বন্ধ হয়।
- ভয়েস → লেখা: ফোনের SpeechRecognizer, লেখা → উত্তর: Gemini, উত্তর → ভয়েস: ফোনের TextToSpeech।

## Olivia ও অর্ব ডিজাইন
- সহকারীর নাম **Olivia**। "Olivia" বলে ডাকলে সাড়া দেয়, নাম জিজ্ঞেস করলে বলে সে Olivia। "Mic: always on" মোডে Olivia নাম ধরে ডাকলে তবেই জাগে (ডাকার পর ২০ সেকেন্ড কথোপকথন চলে)।
- **১০টি অর্ব ডিজাইন**: Nebula, Ember, Aurora, Dusk, Gold, Ice, Rose, Mono, Neon, Royal। লং-প্রেস মেনুর "Orb design" থেকে বাছুন।
- বলেও বদলানো যায়: "ei orb bhalo lagche na", "change the orb", "অন্য অর্ব দাও" বললে পরের ডিজাইন আসে। "red orb", "green orb", "লাল অর্ব" বললে সেই রঙের ডিজাইন আসে।
- Gemini মডেল বন্ধ হয়ে গেলে অ্যাপ নিজেই Google থেকে নতুন Flash মডেল খুঁজে চালায় (ডিফল্ট `gemini-3.6-flash`)।

## APK বানানো (পিসি ছাড়া)
১. GitHub-এ নতুন রিপো খুলে এই জিপের সব ফাইল আপলোড করুন (`.github` সহ)।
২. Actions → **Build Lite Debug APK** → Run workflow।
৩. Releases থেকে `ARKITAK-LITE-debug.apk` নামিয়ে ইনস্টল করুন।

## ফাইল
| ফাইল | কাজ |
|---|---|
| `MainActivity.kt` | কালো স্ক্রিন, API key ডায়ালগ, মেনু, পারমিশন |
| `AssistantEngine.kt` | শোনা → Gemini → বলা লুপ, অর্বের state ও আওয়াজের স্তর |
| `GeminiClient.kt` | Gemini REST কল (বাড়তি লাইব্রেরি ছাড়া) |
| `FloatingOrbService.kt` | ভাসমান ছোট অর্ব (foreground service) |
| `OrbView.kt`, `assets/orb.html`, `three.min.js` | আপনার ARKITAK অর্ব |

## জানা সীমা (আমি কম্পাইল বা ফোনে চালাইনি)
- অর্ব আলাদা ভাবে ব্রাউজারে রেন্ডার করে দেখেছি। Kotlin কোড এখনো কম্পাইল হয়নি, প্রথম GitHub বিল্ডে এরর এলে লগ পাঠান।
- ডিফল্ট মডেল `gemini-2.5-flash`। বন্ধ হয়ে গেলে মেনু থেকে মডেলের নাম বদলান।
- কিছু ফোনে SpeechRecognizer শুরুতে বিপ শব্দ করে, আর ব্যাকগ্রাউন্ডে মাইক নির্ভর করে ফোনের কোম্পানির নিয়মের উপর।
- বাংলা ভয়েসের জন্য ফোনে Google TTS-এর বাংলা ভয়েস ডাউনলোড থাকতে হবে।
