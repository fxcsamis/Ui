# ARKITAK wake word: Vosk (name) and Manual (gesture / tile / widget)

The DSP engine was removed: Android lets only the phone maker's own apps use the DSP hotword hardware.

* **Vosk**: says "Hey Olivia" / "Hey ARKITAK" to wake up (offline, needs the model, see setup-vosk-model.sh).
* **Manual**: the swipe-up gesture / power button (set ARKITAK Lite as the default digital assistant), the Quick Settings tile, the home widget.
  The gesture opens a black screen with the same orb as the app.
* Group chat (Olivia + ARKITAK together): the orb splits in two with a line between them, in the app, in the gesture screen and in the floating avatar.
